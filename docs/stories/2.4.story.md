# Story 2.4: Single-Server WebSocket Communication for Cross-Instance Popup Routing

## Status
**Draft** - Ready for implementation

## Story
As a developer using the popup MCP extension across multiple VS Code instances, I want popup requests to appear in the correct workspace window, so that I can see contextually relevant prompts in the appropriate development environment.

## Background Context
The current multi-instance coordination system successfully:
- ✅ Elects one server instance per machine
- ✅ Registers all client instances with their workspace paths  
- ✅ Routes popup requests to the correct target instance
- ❌ **FAILS** when trying to display popups in client instances because there's no communication channel

**Current Error:** `Target instance not accessible` - Server can identify the correct client but cannot communicate with it.

### WebSocket Server (Server Instance Only)
Integrated with existing MCP HTTP server:

```typescript
// Server instance - single WebSocket server
class ServerPopupCoordinator {
  private wss: WebSocketServer;
  private clientConnections = new Map<string, WebSocket>(); // workspace -> websocket
  
  setupWebSocketServer(httpServer: http.Server) {
    // Reuse existing HTTP server - no additional port needed!
    this.wss = new WebSocketServer({ 
      server: httpServer, 
      path: '/popup-ws' 
    });
    
    this.wss.on('connection', (ws, request) => {
      ws.on('error', console.error);
      
      // Client must identify itself with workspace path
      ws.on('message', (data) => {
        const message = JSON.parse(data.toString());
        
        if (message.type === 'register') {
          // Register client connection
          this.clientConnections.set(message.workspacePath, ws);
          logger.info(`Client registered: ${message.workspacePath}`);
        } else if (message.type === 'popup_response') {
          // Handle popup response from client
          this.handlePopupResponse(message);
        }
      });
      
      // Clean up on disconnect
      ws.on('close', () => {
        this.removeClientConnection(ws);
      });
      
      // Heartbeat
      ws.on('pong', () => { ws.isAlive = true; });
    });
    
    // Ping clients every 30s
    setInterval(() => {
      this.wss.clients.forEach(ws => {
        if (!ws.isAlive) return ws.terminate();
        ws.isAlive = false;
        ws.ping();
      });
    }, 30000);
  }
  
  async routePopupToClient(workspacePath: string, popupRequest: PopupRequest) {
    const ws = this.clientConnections.get(workspacePath);
    if (!ws || ws.readyState !== WebSocket.OPEN) {
      throw new Error('Client not connected');
    }
    
    return new Promise((resolve, reject) => {
      const timeout = setTimeout(() => reject(new Error('Timeout')), 30000);
      
      const responseHandler = (data: any) => {
        const response = JSON.parse(data.toString());
        if (response.requestId === popupRequest.requestId) {
          clearTimeout(timeout);
          ws.off('message', responseHandler);
          resolve(response);
        }
      };
      
      ws.on('message', responseHandler);
      ws.send(JSON.stringify({
        type: 'popup_request',
        ...popupRequest
      }));
    });
  }
}
```

### WebSocket Client (Client Instances)
Simple WebSocket clients that connect to server:

```typescript
// Client instances - simple WebSocket clients
class ClientPopupHandler {
  private ws: WebSocket;
  private workspacePath: string;
  
  async connect(serverPort: number, workspacePath: string) {
    this.workspacePath = workspacePath;
    this.ws = new WebSocket(`ws://localhost:${serverPort}/popup-ws`);
    
    this.ws.on('open', () => {
      // Register with server
      this.ws.send(JSON.stringify({
        type: 'register',
        workspacePath: this.workspacePath
      }));
    });
    
    this.ws.on('message', async (data) => {
      const message = JSON.parse(data.toString());
      
      if (message.type === 'popup_request') {
        // Show popup locally and respond
        const userResponse = await this.showPopupLocally(message);
        
        this.ws.send(JSON.stringify({
          type: 'popup_response',
          requestId: message.requestId,
          response: userResponse
        }));
      }
    });
    
    // Auto-reconnect on disconnect
    this.ws.on('close', () => {
      setTimeout(() => this.connect(serverPort, workspacePath), 5000);
    });
    
    this.ws.on('error', console.error);
  }
}
```

### Connection Management
- **Single Port**: WebSocket server shares HTTP server port (e.g., 9003)
- **Client Registration**: Clients identify themselves with workspace path on connect
- **Health Monitoring**: 30-second ping/pong heartbeat (industry standard)
- **Reconnection**: Clients automatically reconnect on connection loss
- **Graceful Degradation**: Server shows popups locally if client unreachable

## Technical Research Findings

### WebSocket Library Choice: `ws`
- **Industry Standard**: Used by VS Code, Shopify CLI, Live Server extensions
- **Mature & Reliable**: 23M+ weekly downloads, active maintenance
- **TypeScript Support**: Full type definitions available
- **Performance**: Lightweight, efficient for our use case
- **Features**: Built-in ping/pong, compression, error handling

### Best Practices from Research
1. **Heartbeat Pattern**: 30-second ping/pong (used by VS Code, Live Server)
2. **Error Handling**: Always include `ws.on('error', console.error)`
3. **Connection Tracking**: Use `clients.forEach()` for broadcasting
4. **Graceful Shutdown**: Clean up intervals and connections
5. **Security**: Bind to localhost only, no authentication needed (local communication)
